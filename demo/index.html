ai-threads

A person and one AI coding session, talking in numbered threads. Write in a thread, open a new one with the box at the bottom, or branch one off with the button next to Send: each message goes into the session's inbox, the session is woken to read it, and its answer comes back split by thread.

Everything runs in this tab. The real ai-threads library keeps its files in memory, its hooks deliver each message, its markup parser splits the answers and view() hands the threads to chat-thread, which draws them. Only the session is pretend: a script with canned answers. Nothing calls a model, and every name and message here is made up.
